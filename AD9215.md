# AD9215 — ADC Suitability Analysis for ultr4rick

*Analog Devices AD9215: 10-bit pipeline ADC. Specs from ADI datasheet Rev. B, Digi-Key/LCSC product listings, and ADI EngineerZone posts. Flags note where the full PDF was not directly retrievable.*

**Where it fits:** Potential alternative to the ADC10065 (TI, 10-bit, 65 Msps) used in pic0rick. Luc asked whether AD9215 could work for ultr4rick's 65 Msps acquisition path.

---

## Architecture

The AD9215 is a classic switched-capacitor pipeline ADC — the same architecture as the ADC10065. Both share:
- Differential sample-and-hold (SHA) front end (unbuffered, switched-capacitor)
- 10-bit pipeline conversion
- 10-bit parallel CMOS output bus
- Single-clock operation
- Internal voltage reference (overridable)

No delta-sigma, no successive approximation. The SHA-based front end means both chips require an external FDA (fully differential amplifier) or transformer to drive the input optimally.

## Specifications

### Core ADC Parameters

| Parameter | AD9215-65 | AD9215-80 | AD9215-105 |
|-----------|-----------|-----------|------------|
| **Resolution** | 10 bit | 10 bit | 10 bit |
| **Sample rate** | 65 Msps | 80 Msps | 105 Msps |
| **SNR** | ~58 dBFS | ~58 dBFS | ~58 dBFS |
| **ENOB** | ~9.3 bits | ~9.3 bits | ~9.3 bits |
| **SFDR** | 77 dBc | 77 dBc | 77 dBc |
| **DNL** | ±0.25 LSB | ±0.25 LSB | ±0.25 LSB |
| **INL** | 0.65 LSB | 0.65 LSB | 0.65 LSB |

*SNR ~58 dBFS is the Nyquist worst-case. Near-DC and mid-band performance will be better. Exact per-frequency performance curves require the datasheet PDF.*

### Analog Input

| Parameter | Value | Notes |
|-----------|-------|-------|
| **Input type** | True differential | SHA (sample-and-hold amplifier) |
| **Single-ended** | Supported | Dynamic performance degrades at high frequency |
| **Full-scale range** | 1 Vpp to 2 Vpp differential | Pin-selectable; 2 Vpp = 2 × VREF |
| **Analog input BW (−3 dB)** | **300 MHz** | Well above Nyquist at all speed grades |
| **Input impedance** | ~1 kΩ typ in track mode | Switched-cap; kick-back present; FDA driver recommended |
| **Common-mode voltage** | ~mid-supply (~1.5 V typ) | Internally set; external common-mode bias needed for single-ended use |

The 300 MHz analog bandwidth means harmonics and aliasing products from 20–100 MHz transducer signals are within ADC range. This is an advantage for wideband ultrasound NDT or multi-frequency operation.

### Digital Output

| Parameter | Value |
|-----------|-------|
| **Interface** | 10-bit parallel CMOS |
| **LVDS option** | No — CMOS only |
| **Output voltage** | 3.3 V CMOS (DRVDD = 3.3 V) or 2.5 V CMOS (DRVDD = 2.5 V) |
| **Data format** | Offset binary or two's complement (pin-selectable) |
| **Output enable** | Yes (OEB pin) |
| **SPI/serial control** | None — pin-strap configuration only |

### Supply and Power

| Parameter | AD9215-65 | AD9215-80 | AD9215-105 |
|-----------|-----------|-----------|------------|
| **AVDD** | 3.0 V nom (2.7–3.3 V) | same | same |
| **DRVDD** | 2.5 V or 3.3 V | same | same |
| **Power (typ)** | **96 mW** | **104 mW** | **120 mW** |

Single-supply operation is possible: tie both AVDD and DRVDD to 3.3 V.

### Clock Input

| Parameter | Value |
|-----------|-------|
| **Clock standard** | Single-ended CMOS (not LVPECL, not LVDS) |
| **Duty cycle stabilizer** | Yes — on-chip DCS corrects wide duty-cycle variation |
| **Max clock** | 105 MHz (105 Msps grade) |

The on-chip DCS is a practical advantage: the RP2350B PIO or a standard CMOS oscillator can drive CLK directly without LVPECL translation. Duty cycle need not be tightly controlled.

### Voltage Reference

Internal bandgap reference (VREF = 1.0 V typical). External reference supported via the VREF pin. With internal VREF at 1.0 V, full-scale = 2 Vpp differential (SHA has 2× gain from VREF).

| Package | Part suffix | Size |
|---------|-------------|------|
| TSSOP-28 | BRUZ | 9.7 mm × 4.4 mm |
| LFCSP-32 | BCP | 5 mm × 5 mm |

## Family: Pin-Compatible Upgrades

The AD9215 shares a footprint with three higher-resolution siblings. This is the most architecturally significant fact for ultr4rick PCB design:

| Part | Resolution | Max Fsample | Power | Drop-in? |
|------|-----------|-------------|-------|---------|
| **AD9215** | 10-bit | 105 Msps | 120 mW | — baseline |
| **AD9235** | **12-bit** | 65 Msps | ~165 mW | ✓ pin-compatible |
| **AD9236** | **12-bit** | 80 Msps | ~366 mW | ✓ pin-compatible |
| **AD9245** | **14-bit** | 80 Msps | ~400 mW | ✓ pin-compatible |
| AD9255 | 14-bit | 125 Msps | higher | ✗ different package/pinout |

**A PCB designed for AD9215 can be populated with AD9245 for 14-bit resolution with no board change.** This is a meaningful design advantage: prototype with 10-bit at lower cost, upgrade to 14-bit if dynamic range proves insufficient, without a PCB re-spin.

The ADC10065 has no pin-compatible family — any resolution upgrade requires a new PCB layout.

## Comparison to ADC10065

The ADC10065 is the current baseline for pic0rick and ultr4rick.

| Parameter | ADC10065 (TI) | AD9215 (ADI) | Advantage |
|-----------|--------------|--------------|-----------|
| Resolution | 10-bit | 10-bit | Tie |
| Max Fsample | 65 Msps | 105 Msps | AD9215 (+61%) |
| SNR | ~58 dBFS | ~58 dBFS | Tie |
| ENOB | ~9.6 bits | ~9.3 bits | ADC10065 slight edge |
| Analog input BW | 200 MHz | **300 MHz** | AD9215 |
| FS range | 1 Vpp | 1–2 Vpp | AD9215 |
| Supply | 3.3 V single | 3.0 V + DRVDD | ADC10065 simpler |
| **Power @ 65 Msps** | **68 mW** | **96 mW** | **ADC10065 (−29%)** |
| Clock input | CMOS | CMOS + DCS | AD9215 (DCS) |
| SPI interface | None | None | Tie |
| Package | SSOP-28 / QFP-32 | TSSOP-28 / LFCSP-32 | Not pin-compatible |
| Pin-compatible family | None | AD9235/9245 (12/14-bit) | **AD9215** |
| Unit price (1pc) | ~$6–8 | ~$17–27 | **ADC10065 (2–4× cheaper)** |
| Availability | Better stocked | Limited | ADC10065 |

### ENOB note

The ADC10065 datasheet publishes ENOB 9.6 bits (measured); AD9215's ~9.3 bit figure is derived from the SNR spec (ENOB = (58 − 1.76) / 6.02). The ADC10065 has a slight measured dynamic range advantage. For ultrasound at 1–10 MHz, both are practically equivalent — a ~0.3-bit ENOB difference is not the limiting factor.

## Suitability for ultr4rick

### Does it work technically?

**Yes.** The AD9215 is functionally compatible with the ultr4rick architecture:
- 10-bit CMOS parallel output → same interface to RP2350B PIO/GPIO as ADC10065
- CMOS clock → directly drivable from RP2350B PIO
- 3.3 V supply → compatible with board power rails
- 300 MHz analog bandwidth → adequate for any transducer up to ~150 MHz fc (well beyond any practical ultrasound target)
- SNR/ENOB → equivalent to ADC10065 for pulsed ultrasound A-mode

### What changes from ADC10065?

1. **PCB re-layout required.** TSSOP-28 vs SSOP-28 — different body dimensions, different pin pitch. Not a drop-in.
2. **Power increases by ~41%.** 96 mW vs 68 mW. For a multichannel board this adds up: an 8-channel front-end would draw 768 mW from the ADCs alone vs 544 mW with ADC10065.
3. **Cost increases 2–4×.** $17–27 vs $6–8.
4. **Separate DRVDD rail.** Minor routing addition (can tie to 3.3 V).

### When would AD9215 be preferred?

| Use case | AD9215 advantage |
|----------|-----------------|
| Need 105 Msps (not just 65 Msps) | 105 Msps grade; no ADC10065 equivalent |
| Future 12 or 14-bit upgrade on same PCB | AD9235 / AD9245 drop-in pin swap |
| Single vendor strategy (all ADI: AD8338 VGA + AD9215 ADC) | Vendor consolidation |
| Wideband input > 200 MHz (NDT above 50 MHz fc) | 300 MHz BW vs 200 MHz |

### Recommendation

**For ultr4rick at 65 Msps, the ADC10065 remains the better choice:**
- 29% lower power (meaningful for battery-powered wearable derivatives)
- 2–4× lower cost
- Better availability
- No change from pic0rick baseline → firmware and analog chain directly reuse

**AD9215 becomes interesting if:**
- You want to run at 80 or 105 Msps (e.g., to support 5–10 MHz transducers with 4× oversampling headroom)
- You plan a 14-bit upgrade path on the same PCB (place AD9215 footprint, populate AD9245 later)
- You're already standardizing on ADI components (AD8338 VGA is already on the BOM)

If speed above 65 Msps is needed and power is not the constraint, **AD9215-105 (105 Msps) is preferable to the ADC10065** — it directly fills the gap with the same interface complexity.

## Interface to RP2350B

Identical to ADC10065 approach. 10-bit parallel CMOS → 10 GPIO pins. Clock from PIO sideset. OTR (over-range) flag on one additional GPIO. Total: 12 GPIO pins for the ADC interface (same count as ADC10065 path).

No changes to PIO programs — the data capture state machine (sample on CLK rising edge, latch 10 bits) is identical between the two parts.

| | |
|---|---|

| **Vs ADC10065 at 65 Msps** | More expensive (+2–4×), more power (+41%), same resolution and SNR, wider BW (300 vs 200 MHz) |
| **Key advantage** | 105 Msps grade; 14-bit drop-in upgrade to AD9245 |
| **Key disadvantage** | Cost and power; limited stock |
| **Recommended when** | Need > 65 Msps, or want PCB-level 14-bit upgrade path |
| **Not recommended when** | Power-constrained, cost-sensitive, or 65 Msps suffices |
