# AD833x VGA Family — Comparison for Ultrasound Use

*AD8331, AD8332, and AD8338 are Analog Devices variable-gain amplifiers (VGAs) used in ultrasound receive chains for time-gain compensation (TGC). All specs from Analog Devices datasheets unless noted.*

**Where used in this project:**
- **AD8338** — deployed in WULPUS PRO (see `OtherSystems/WULPUS_PRO.md`). Chosen for low power on a 3 V single supply.
- **AD8331/AD8332** — cited in `MSP430FR5043.md` as external TGC option for WULPUS-class designs. Used in clinical and portable ultrasound instruments at 5 V.

---

## Architecture Overview

### AD8331 / AD8332 — X-AMP ultrasound TGC VGA

AD8331 (single channel) and AD8332 (dual channel) share the same silicon; they ship from the same datasheet (Rev. I). Both use ADI's **X-AMP** (exponential amplifier) architecture:

```
LNA (fixed gain)  →  X-AMP VGA (analog VGAIN)  →  output limiter
```

- **LNA:** Fixed-gain, low-noise preamplifier with programmable input impedance via a single external resistor on the RIN pin. LNA gain: **19 dB** single-ended in, differential out.
- **VGA:** X-AMP core, gain set by analog voltage on VGAIN pin. Logarithmically conformant — gain in dB is linear with VGAIN voltage. This is purpose-built for TGC: tissue attenuation is approximately linear in dB with depth (0.5 dB/cm/MHz), so a linear voltage ramp → constant-dB/cm compensation.
- **HI/LO mode:** A single logic pin (HILO) shifts the entire gain range by +12 dB, without changing the gain law.
- **Output limiter:** Adjustable output clamp for ADC overload protection.

**AD8334** (quad-channel version of the same X-AMP architecture, LFCSP-48) exists for 4-element array designs.

### AD8338 — low-power wearable VGA

```
Input attenuator/impedance network  →  Core VGA  →  differential output driver
```

- No fixed-gain LNA stage; gain is entirely in the VGA core.
- Differential input and output, fully balanced signal path.
- Linear-in-dB gain law (no X-AMP naming, but same mathematical property).
- **MODE pin** inverts the gain slope (rising VGAIN → decreasing gain), useful for AGC feedback loops.
- **VAGC pin** for external AGC capacitor; time constant sets AGC hold.
- **OFSN pin** for output DC offset correction.
- Internal 1.5 V voltage reference.

## Gain Law Detail

### AD8331 / AD8332 — X-AMP

The X-AMP gain is exactly linear-in-dB with VGAIN:

```
G [dB] = 50 × VGAIN [V] − 6.5   (LO mode, typ)
G [dB] = 50 × VGAIN [V] + 5.5   (HI mode, typ)
```

For a tissue attenuation of 0.5 dB/cm/MHz and a 2.25 MHz transducer, compensating 4 cm depth requires: 0.5 × 4 × 2.25 = 4.5 dB gain increase per cm. At sound speed 1540 m/s, 1 cm round-trip = 13 µs. A VGAIN ramp rate of 4.5 dB / (50 dB/V × 13 µs) ≈ 6.9 V/ms. This is a gentle ramp — easily generated by an RC network or a DAC.

### AD8338

```
G [dB] = 80 × VGAIN [V] − 8   (standard config, typ)
```

VGAIN from 0.1 V (G ≈ 0 dB) to 1.1 V (G ≈ 80 dB). The 80 dB/V sensitivity is steeper than the AD8331's 50 dB/V — same 1 V control range, 60% more gain. For TGC via an RC ramp, the RC time constant must be tuned more carefully to hit a specific dB/µs slope. WULPUS PRO uses this approach: an RC charging network on the GAIN pin provides an exponentially-shaped ramp, mapped to approximately 40 dB of TGC compensation over the receive window.

## Noise Figure in Depth

AD8331/AD8332 publish NF in the datasheet for four configurations: resistive vs active termination × 50 Ω vs 200 Ω source.

**Active termination** means the RIN pin is used to present the matched impedance to the source without the thermal noise of a physical resistor — the LNA drives the termination actively, reducing the noise contribution by ~3–6 dB. For a transducer with source impedance ~50–100 Ω, active termination gives the lowest system NF.

**Key numbers:**
- 50 Ω active: **4.1 dB** — typical for 50 Ω ultrasound probe cables
- 200 Ω active: **2.0 dB** — better choice if transducer impedance is ~200 Ω at the operating frequency

AD8338 does not publish NF. From the input-referred voltage noise of 4.5 nV/√Hz at max gain, the equivalent NF at 50 Ω source is:

```
NF = 20 log10(e_in / e_Johnson) = 20 log10(4.5 nV/√Hz / 0.91 nV/√Hz) ≈ 13.9 dB
```

This is substantially worse than the AD8331/AD8332 (4.1 dB at 50 Ω active). However, this comparison is unfair for the WULPUS PRO use case: WULPUS PRO uses a 6 dB fixed OPA836 pre-amplifier before the AD8338. The OPA836's noise figure (~4–6 dB) dominates, and the AD8338's noise contribution is suppressed by the 6 dB pre-gain. Effective system NF is set by the OPA836, not the AD8338.

## Bandwidth vs Application Frequency

| Chip | −3 dB BW | Max usable transducer fc | Notes |
|------|----------|--------------------------|-------|
| AD8331 | **120 MHz** | ~60 MHz | Clinical probes 1–20 MHz: well within range |
| AD8332 | **100 MHz** | ~50 MHz | Same; bandwidth reduction from dual layout |
| AD8338 | **18 MHz** | ~9 MHz | Adequate for ≤5 MHz wearable transducers |

For wearable ultrasound at 1–5 MHz (WULPUS PRO range), the AD8338's 18 MHz bandwidth is more than sufficient — the Nyquist limit for an 8 Msps ADC is 4 MHz, so the ADC, not the VGA, determines the system bandwidth ceiling.

For pic0rick at 65 Msps (usable to ~30 MHz), the AD8338's 18 MHz ceiling is a genuine bottleneck. The AD8331/AD8332 (120/100 MHz BW) are the correct choice.

## Supply Voltage and Power — The Key Trade-off

| | AD8331/AD8332 | AD8338 |
|-|---------------|--------|
| Supply | 5 V only (4.5–5.5 V) | 3–5 V |
| LiPo direct (3.7 V) | ❌ Requires boost or 5 V rail | ✓ Runs directly |
| Power per channel (active) | **125–138 mW** | **9–30 mW** |
| Power ratio (1 ch) | 1× | **~0.12× (8× lower)** |

For wearable systems on a single-cell LiPo:
- AD8331/AD8332 require a 5 V boost converter, adding quiescent current and board space. At 125 mW/channel, a 4-channel receive front-end draws 500 mW from the VGA alone — incompatible with sub-100 mW wearable budgets.
- AD8338 at 9–30 mW per channel runs directly from the LiPo at 3.7 V. For WULPUS PRO's single receive chain, this is 9–30 mW vs the 125 mW the AD8331 would cost.

**WULPUS PRO's choice of AD8338 over AD8331 saves ~100 mW** — a significant fraction of its 35–58 mW total core budget.

## Gain Control Interface

All three chips use **analog voltage control** — no SPI or I²C. The gain control pin sources/sinks negligible current; driving it from:
- A DAC (e.g., MCP4921, 12-bit SPI DAC) for programmable depth-gated gain steps
- A resistor-capacitor RC ramp for automatic TGC (the WULPUS PRO approach: RC charges during receive window)
- An op-amp integrator for linear-in-time gain ramp

The absence of SPI simplifies firmware: the MCU sets a DAC register once per acquisition (or lets the RC run autonomously), rather than managing a register protocol per gain step.

## TGC Implementation with RC Ramp (AD8338, WULPUS PRO approach)

```
VDD ──┬── R_TGC ──┬── GAIN pin (AD8338)
      │           │
     (at       C_TGC
     TX pulse)   │
      │          GND
  Reset switch
  (short C_TGC to GND at TX pulse, then open to charge)
```

During TX pulse: the switch discharges C_TGC to 0 V → GAIN = 0 dB.
After TX pulse: C_TGC charges through R_TGC toward VDD. The exponential ramp on GAIN pin maps to a rising gain profile that approximately tracks tissue attenuation.

WULPUS PRO achieves 40 dB of TGC slope this way. The RC time constant is tuned to span the receive window (e.g., ~60 µs for 4 cm depth at 1540 m/s round-trip).

The same approach works for AD8331/AD8332: connect the RC ramp to the VGAIN pin. The X-AMP's 50 dB/V sensitivity means a 0.8 V swing produces 40 dB of TGC, requiring an RC that charges from ~0.1 V to ~0.9 V over the receive window.
